# 하벳 현재 운영 상태 보존 작업

2026-11-18 사용자 요청: 기존 GitHub Pages 방식으로 작업을 진행하되 현재 사이트 상태를 유지하고 지시 외 임의 변경 금지.

현재 운영 도메인은 Netlify를 가리킨다. 최신 main에는 현재 운영본과 다른 프리미엄 디너 가격159000 및 상단 custom001 코드가 있다. 이를 현재 운영으로 자동 반영하지 않는다. main 및 기존 커밋 이력은 그대로 보존하고 별도 브랜치에서 작업한다.

기준 파일은 현재 운영 공개46파일의 백업과 이를 바탕으로 만든 /home/ubuntu/havet-display-stability-site.zip 의 검수된 수정본이다. ZIP SHA256=73aed32405774b069e9053635549a4f3d4361ee63514d8f34d4c646b4d403ba4. ZIP은 이미 로컬 PC/모바일87건과 내용보존277건을 통과했으며, 운영공개46파일은 기존ETag대조에서 변경없음이었다.

별도 브랜치에는 이 수정본의 정적47파일을 그대로 복사한다. Netlify 참고설정 _headers는 GitHub Pages에서 작동하지 않으므로 복사하지 않고 기존ZIP에 보존한다. 기존CNAME/Pages설정/DNS/저장소main/다른파일은 그대로 둔다. 저장소작업지침에 따라 본지시서와CHANGELOG에 준비작업이력을 기록한다. 기존 이미지·문구·가격·폰트·카드순서·메뉴·예약링크·분석·팝업은 현재운영상태를 기준으로 유지한다. 사이트재설계·추가최적화·외부게시판DB수정은 금지한다.

이 브랜치 작업은 코드 보관·복귀 준비일 뿐이며 공개 Pages 배포 또는 DNS전환을 실행하지 않는다. GitHub Pages 공식정책은 온라인사업/전자상거래/상업적거래유도중심사이트의 무료호스팅사용을 제한한다. 하벳의 실제허용여부가 확인되기전에는 호스팅복귀를 강행하지 않는다. 허용여부와 HTTPS·루트/www리디렉션·확장자없는경로·응답헤더보존가능성을 확인하고, 정확한DNS변경값에 대한사용자승인 후에만 운영전환을 별도로 검토한다.

외부그누보드007/009의본문참조3개는별도DB이며본브랜치로교정되지 않는다. 현재Netlify프로젝트·운영파일·DNS·그누보드는 변경하지 않는다.
