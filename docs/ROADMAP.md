# 향후 개발 로드맵 (Roadmap)

하벳 리조트 홈페이지의 장기적인 운영과 디지털나우(PMS) 연동을 위한 개발 계획입니다.
업주의 피드백과 디자인 변경 요청에 따라 유연하게 조정될 수 있습니다.

## 1단계: 안정화 및 기본 연동 (현재 진행 중)

- [x] 4월 28일 기준 전체 페이지 및 기능 복구 완료
- [x] 스페셜 오퍼 이미지 로컬화 및 최적화
- [x] 시즌별(Summer/Winter) 토글 기능 구현
- [ ] 디지털나우(PMS) 예약 시스템 기본 연동 테스트
- [ ] `reservation.html` 페이지 내 PMS 예약 위젯 삽입

## 2단계: 디자인 고도화 및 피드백 반영

- [ ] 업주 피드백 수집 체계 구축 (`FEEDBACK.md` 활용)
- [ ] 메인 페이지(`index.html`) 레이아웃 개선 (레스토랑 베르데 비중 확대)
- [ ] 객실 상세 페이지(`room_*.html`) 내 어메니티 아이콘 디자인 변경
- [ ] 모바일 환경에서의 네비게이션 메뉴 사용성 개선
- [ ] 갤러리(`gallery.html`) 이미지 로딩 속도 최적화 (Lazy Loading)

## 3단계: PMS 완전 연동 및 자동화

- [ ] 디지털나우(PMS) API를 활용한 실시간 객실 잔여 수량 표시
- [ ] 예약 완료 시 자동 알림톡/이메일 발송 시스템 연동
- [ ] 시즌별 요금제 자동 적용 스크립트 구현
- [ ] 다국어 지원 (영어, 일본어, 중국어) 초기 기획

## 4단계: 마케팅 및 분석 도구 통합

- [ ] Google Analytics 4 (GA4) 및 네이버 애널리틱스 연동
- [ ] 스페셜 오퍼 클릭률(CTR) 분석을 위한 이벤트 트래킹
- [ ] SEO(검색 엔진 최적화) 고도화 (메타 태그, Open Graph 개선)
- [ ] 고객 리뷰 및 평점 시스템 도입 검토
